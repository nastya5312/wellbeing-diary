# Дневник самочувствия

Личное веб-приложение (PWA) для iPhone: сон, еда, лекарства, добавки, симптомы и поиск повторяющихся совпадений между ними.

**Все данные хранятся только на телефоне** (IndexedDB). Сервера нет, ничего никуда не отправляется. В этом репозитории только код — никаких данных здоровья.

Приложение показывает совпадения в записях, а не диагнозы и не причины. Это не медицинское изделие и не замена врачу.

Адрес: https://nastya5312.github.io/wellbeing-diary/

Версия 1.6.0. Проверка на телефоне — в [CHECKLIST_iPhone.md](CHECKLIST_iPhone.md).

## Как поставить на iPhone

1. Открыть адрес выше в **Safari** (именно Safari, не Chrome).
2. Нажать кнопку **«Поделиться»** (квадрат со стрелкой вверх) внизу экрана.
3. Пролистать вниз и выбрать **«На экран «Домой»»**.
4. Нажать **«Добавить»**.
5. Открывать приложение с иконки «Дневник» на экране «Домой». После первого открытия оно работает без интернета.

## Как обновлять

Когда выходит новая версия, внизу появляется плашка **«Доступна новая версия»** → нажать **«Обновить»**. Записи при обновлении не стираются.

## Резервная копия

Восстановление (например, после переустановки иконки): открыть приложение → карточка «Восстановить из копии» на пустом экране (или «Ещё» → «Резервная копия» → «Восстановить из файла») → выбрать файл `dnevnik-kopiya-….json` → «Заменить всё».

«Ещё» → «Резервная копия» → сохранить файл в «Файлы» (лучше в iCloud Drive). Приложение напоминает раз в 7 дней.

## Отчёт для врача

«Ещё» → «Отчёт для врача» (или кнопка на вкладке «Анализ») → период → «Сохранить PDF (A4)» → «Сохранить в Файлы». PDF собирается в самом приложении (системная печать в приложении с экрана «Домой» на iPhone не работает). Один лист A4, чёрно-белый.

## Таблицы и настройки

«Ещё» → «Резервная копия» → «Сохранить таблицы CSV» — 5 таблиц для Excel/Numbers (только просмотр, не для восстановления).
«Ещё» → «Настройки»: тема, граница дня, параметры анализа, проверка обновления, удаление всех данных (с двойным подтверждением).

## Для разработки

```bash
npm install
npm run dev      # локальный сервер
npm test         # тесты (Vitest)
npm run build    # сборка в dist/
```

Публикация: при push в ветку `main` GitHub Actions собирает приложение и выкладывает на GitHub Pages (`.github/workflows/deploy.yml`).

Иконки: исходник `scripts/icon.svg`, PNG генерируются скриптом `scripts/make-icons.mjs` (нужен Playwright).
