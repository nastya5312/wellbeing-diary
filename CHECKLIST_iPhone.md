# Проверка на iPhone (версия 1.2.0)

Отмечай галочками. Если пункт не получился — запиши, что именно увидела, и пришли.
**Перед проверкой:** «Ещё» → «Резервная копия» → «Сохранить копию» (на случай, если что-то пойдёт не так).

## Установка и обновление
- [ ] Адрес открывается в Safari, «Поделиться» → «На экран «Домой»», иконка «Дневник» появилась.
- [ ] Запуск с иконки — без адресной строки Safari, на весь экран.
- [ ] После обновления на плашке «Доступна новая версия» → «Обновить» записи на месте.

## Без интернета
- [ ] Включить авиарежим → открыть приложение с иконки → открывается, записи видны.
- [ ] В авиарежиме добавить симптом и отметить «День заполнен» → записалось. Выключить авиарежим.

## Ежедневная работа
- [ ] «Сегодня»: отметка из чек-листа одним касанием; повторное касание снимает отметку.
- [ ] Симптом: после касания спрашивает силу; «Отметила случайно — отменить» работает.
- [ ] «Стул», «Сон», «Самочувствие»: открываются, сохраняются, появляются карточками.
- [ ] «Измерения»: внести вес, потом ещё раз другим числом — осталось одно значение.
- [ ] Время у лекарства/добавки меняется касанием на «07:05».
- [ ] Свайп влево по записи удаляет её; касание — открывает для правки.

## Вид
- [ ] Тёмная тема: «Ещё» → «Настройки» → «Тёмная» и «Как в iPhone» (проверь и при включённой тёмной теме iPhone).
- [ ] Крупный шрифт: «Настройки» iPhone → «Экран и яркость» → «Размер текста» — крупнее; ничего не обрезается.
- [ ] Верхний край и нижняя вкладка не прячутся под «чёлкой» и «домашней полосой».
- [ ] Поля ввода: при касании страница не приближается.

## Сохранность данных
- [ ] Полностью закрыть приложение (смахнуть вверх) → открыть: записи на месте.
- [ ] Через 1–2 дня снова открыть: записи на месте (особенно важно, если дольше недели не открывать).
- [ ] «Ещё» → «Резервная копия»: пункт «Хранилище» не показывает предупреждений.

## Копия и восстановление
- [ ] «Сохранить копию» → «Сохранить в Файлы» → файл `dnevnik-kopiya-…json` виден в «Файлах».
- [ ] Восстановление «Добавить недостающее»: дублей не появилось.
- [ ] «Скачать в «Загрузки»» (запасная кнопка): файл появился в «Загрузках».
- [ ] «Сохранить таблицы CSV» → 5 файлов → открыть в Numbers/Excel.

## Анализ и отчёт
- [ ] «Как обычно»: «Настроить» → отметить свои позиции → кнопка «Всё как обычно» отмечает только их.
- [ ] «Отчёт для врача» → «Сохранить PDF (A4)» → «Сохранить в Файлы» → PDF открывается, 1 лист.
- [ ] В «Файлах» открыть PDF → «Поделиться» → «Напечатать» (если есть принтер).
- [ ] На своих данных: до 30 заполненных дней «Анализ» показывает «Прогресс данных».

## Что не проверялось мной (нужен твой телефон)
Всё в этом списке выполнено только в браузере на компьютере, с имитацией экрана iPhone. На настоящем iPhone **не проверены**:
меню «Поделиться» для файлов, кнопка «Скачать в «Загрузки»», ссылка на «Файлы», чтение буфера, работа в режиме «с экрана Домой» после недели без запуска (политика очистки Safari), жесты свайпа пальцем, реальный размер текста iOS.
